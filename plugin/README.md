# 光鸭 STRM 同步 · DIAN-115 插件 1.0.0

单账号，顶部为 STRM 同步、文件清理、账号登录三个页签；任务进度和结果统一在系统任务队列查看。要求宿主插件 API 3.8。

## 安装

导入 `guangya-strm-1.0.0.dian115p` 升级，保留原 ID、账号凭证、规则和同步状态。不需要卸载旧版。旧任务运行期间宿主可能拒绝升级，请先完成任务。

## 云盘名称和路径

编辑规则时从宿主 `/api/cd2/clouds` 自动读取已挂载的光鸭名称，只读显示，例如 `/光鸭云盘`。仅有一个光鸭挂载时自动选中；多个挂载时仅沿用可明确匹配的既有挂载，不凭空选择账号。无挂载、接口失败或有多个无法匹配的挂载会报明原因。

源路径由光鸭账号浏览选择，例如 `/已整理`；下面按内置 115 样式显示 `CD2路径：/光鸭云盘/已整理`。CD2 备用入口保留在网盘浏览失败时的目录选择器中，高级设置不再出现备用或网盘根目录字段。

CD2 模式生成的 STRM 内容仍是完整路径 `/CloudNAS/CloudDrive/光鸭云盘/已整理/…/视频.mkv`。挂载前缀依据本 NAS 用户提供的原生 115 STRM 适配，同步时确认虚拟目录存在且完整路径被宿主识别为 CD2。不会通过修改显示文字掩盖路径错误。旧规则运行时也会读取实际挂载名称。

链接模式沿用当前 DIAN115 播放回调地址和已保存令牌，源目录仍通过光鸭账号扫描，不依赖 CD2 播放。整理触发需要可匹配的 CD2 云盘目标路径；没有 CD2 挂载时仍可手动或定时使用链接模式。

## 整理后增量与入库信息（待 NAS 验证）

- 整理成功事件与成功历史提取目标父目录，持久化待同步范围。同步扫描该父目录及子目录，保留其他目录的输出索引，不自动删除其他输出。
- 手动同步、定时增量仍扫描选定源目录并跳过未变化输出；定时全量继续重建输出。不注册 CD2 目录监听，没有接入光鸭云端事件推送。
- STRM 或对应元数据写入后登记默认 Emby 刷新请求，最多每分钟合并提交一次全库扫描。必须先在宿主配置默认 Emby，并把插件本地输出目录加入 Emby 媒体库。
- 规则表下方共用“同步与入库日志”，展示待刷新、扫描已提交、库内匹配、无法精确核实和查询错误。电影用 TMDB 身份查询，剧集用 TMDB 与季集覆盖查询；缺少标识时不猜测。
- **库内身份匹配不证明是本次新增文件**：宿主接口不返回媒体路径，可能匹配同一电影或剧集的 115/其他来源。插件不伪造“最近入库”或海报；宿主总览依赖实际媒体库数据。当前无公开 API 可让插件直接写入宿主总览记录。
- 用户此前反馈自动触发未生效；新版事件路径、扫描与入库查询尚未在 NAS 验证，不能宣称现场恢复。刷新错误保留并重试，输出写入成功不等于媒体库入库成功。

## 文件监控链路日志

宿主系统任务队列中打开“同步光鸭 STRM”的任务详情，查看文件变化、来源、父目录扫描范围、新建/更新 STRM 明细及耗时。整理成功事件使用 `upsert`，不监控网盘或 CD2 目录变化。整理事件按 3 秒窗口合并，失败批次不确认监控版本。

共用日志列表仅显示北京时间当天的记录，固定高度滚动，支持单条删除和清空；后台记录和入库检查保留。变化明细最多 100 项，输出写入明细最多 100 项；实际计数和耗时在完成日志中汇总。删除变化只触发扫描，不自动删除本地输出。原生 115 系统运行日志分类表没有公开插件写入接口，本版写宿主任务日志，不伪造原生日志或入库记录。自动触发是否恢复仍待 NAS 现场确认。

## 其他功能

源文件 `视频.mkv` 输出为 `视频.mkv.strm`，避免相同主文件名、不同后缀互相覆盖。元数据同步仅不启用或云端覆盖，单文件上限64MiB。旧版保留本地模式继续兼容，编辑后默认为不启用。

STRM 规则中的“清理孤立”仍然只处理本插件跟踪的本地输出文件。新的“文件清理”页签独立管理光鸭云端清理规则。

## 文件清理

1. 进入“文件清理”，新建规则，通过登录账号选择光鸭子目录，无需 CD2。根目录不能作为清理范围，所选子目录本身保留。
2. 选择删除选中文件、保留选中文件或清理不含保留文件的子目录。后者逐个删除无保留文件子目录中的文件，再从内到外删除已空目录；所选根目录直属文件保留。
3. 文件条件可选全部、视频（含 ISO/M2TS）、字幕、音频、自定义后缀；大小条件为严格小于 MB，支持与类型条件组合 AND/OR。不选文件条件且启用清理空目录时，规则只清理空目录。
4. 排除目录及全部内容保留，含有排除目录的父目录不会被清空。不再提供单次删除上限配置。
5. 已保存规则的“预览”生成逐项清单，确认后执行，清单有效期 10 分钟；“清理”在按钮旁确认后扫描并执行。顶部“一次性清理”打开独立空白配置，不保存规则，预览结果进入任务队列，当前表单保留以便继续清理。
6. 需要定时删除时，在规则中开启“启用此规则”和“加入统一定时执行”，再开启统一定时并保存 Cron。支持五段或秒字段为 0 的六段，例如 `0 0 3 * * *` 表示北京时间每天 03:00。定时默认关闭，等待同步任务完成后执行。
7. Telegram 开始/结束通知默认关闭，开启后使用宿主现有通知渠道。插件不保存 Bot Token。

每次手动执行重新扫描目录树，并逐项核对父目录、ID、名称、大小和修改信息。仅向删除 API 提交清单中的项目，目录必须在删除前确认为空；目录内容并发变化、列表不完整、规则或账号改变时停止。中断任务进入需核对状态，不自动重放删除请求。

清理针对光鸭云端真实文件，不能当作本地 STRM 清理使用。宿主整理、转存等目录不自动加入排除列表；需要整目录保留时，请手动排除。光鸭 API 不提供本插件可确认的原子条件删除，外部客户端在最后一次核对与删除请求之间同时修改网盘仍存在竞争窗口；首次请用专门的小目录验证。

## 当前验证范围
