# 光鸭 STRM 同步与文件清理 1.0.3

作者：yy1105384898。要求 DIAN115 插件 API 3.8，顶部为 STRM 同步、文件清理、账号登录三个页签，共用单个光鸭账号。

## 安装和路径

导入 `guangya-strm-1.0.3.dian115p` 升级，保留原插件 ID、账号和规则。旧任务结束后再升级。

源目录直接从登录的光鸭账号选择，云盘名称从宿主 CD2 挂载读取。CD2 路径模式输出完整路径 `/CloudNAS/CloudDrive/光鸭云盘/已整理/…/视频.mkv`，链接模式使用插件播放回调。源文件 `视频.mkv` 生成 `视频.mkv.strm`。

## 自动同步

开启规则及“实时监控”：监听宿主整理完成事件，并每分钟补查成功记录，按目标父目录触发增量，3 秒合并窗口。这里不监听光鸭网盘变化，不注册 CD2 目录监听。手动和定时增量仍扫描所选源目录并跳过未变化输出；全量重建输出。目录树保留最近全源扫描的统计。

可选同步 NFO、图片、字幕；元数据支持关闭或云端覆盖，单文件上限 64 MiB。排除目录按规则生效。“清理孤立”仅处理本插件跟踪的本地输出。

## 目标已存在时删除重复来源

只处理本功能首次运行后、宿主状态为跳过且原因明确为 **目标文件已存在（跳过-已完成）** 的整理记录，不补删旧历史，不把普通失败当作重复。

目标必须位于已启用且开启实时监控的规则内，来源须在同一光鸭挂载且位于所有 STRM 源目录之外；排除的目标目录不处理。源、目标须为不同非空文件，删除前重读记录、账号和文件状态。

直接调用光鸭删除 API，仅提交来源文件 ID，目标和目录保留。结果不明时停止，不自动重复提交。外部客户端在核对与请求之间修改同一路径仍存在竞争窗口。此功能不调用 Emby 查询判断重复、不自行比较画质，以宿主整理结果为准。

## 日志与媒体库刷新

规则下方共用一个同步日志区，显示实际同步及重复来源清理结果。仅显示北京时间当天记录，固定高度滚动，支持单条删除及清空已结束记录。详情包含路径、原因、生成数量、耗时或错误；重复来源清理明确记录保留目标及删除结果。删除页面记录不清除宿主历史和后台防重放状态。

逐媒体入库匹配查询已移除，不再生成“查询待重试”记录。输出实际变更后仍合并请求默认 Emby 扫描（至多每分钟一次全库刷新），刷新失败可重试。需预先配置默认 Emby，并把 STRM 输出目录加入媒体库；请求成功不证明本次文件已经入库。不写入虚假的宿主总览或原生运行日志。

## 光鸭文件清理

目录从光鸭账号选择，删除直接调用光鸭 API，不经 CD2。支持三种模式：删除选中文件；保留选中文件并删除其余文件；清理不含保留文件的子目录。

条件支持视频、字幕、音频、自定义后缀及大小，并可清理空目录。所选根目录和排除目录保留。仅开启空目录清理时，所有文件保留。宿主整理/转存目录不会自动加入排除，需自行配置。

保存规则后可预览候选并确认执行，或直接在规则旁确认清理。一次性清理使用空白表单，不保存定时规则；预览只扫描统计。清理页任务队列支持单条删除和清空已结束记录。

定时需同时开启规则和统一定时开关，按北京时间执行；`0 0 3 * * *` 为每天 03:00。Telegram 开始/结束通知使用宿主已有渠道。删除前核对目录状态，结果不明时停止，不自动重放。
