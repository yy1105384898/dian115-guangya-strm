# DIAN115 光鸭 STRM 同步插件

面向 DIAN-115 插件平台的光鸭 STRM 同步插件。单账号登录，网盘目录浏览，CD2 路径或链接模式生成 STRM，元数据同步，定时同步和整理结果监控。

## 安装

从 [Releases](https://github.com/yy1105384898/dian115-guangya-strm/releases) 下载 `.dian115p` 文件，在 DIAN115 插件中心导入。当前版本 **0.6.3**，要求宿主插件 API **3.8**。源码中也保留了同版安装包，见 `releases/`。

已有插件使用升级入口，不需要卸载。账号、规则和同步状态由宿主插件存储保留。

## 功能

- 账号登录与设置两个页面，支持短信登录或手动导入凭证。
- 直接浏览光鸭源目录，自动读取 CD2 光鸭挂载名称。
- 生成本地 STRM，支持 CD2 完整路径与播放链接两种模式。
- 定时增量、定时全量；每分钟检测宿主整理成功记录，合并触发对应规则的增量同步。
- 可选同步 NFO、图片、字幕，支持后缀与排除目录设置。
- 孤立文件先预览再确认清理；任务进度统一在宿主系统任务队列查看。

## 使用范围与当前限制

“实时监控”实际通过每分钟检查宿主整理成功历史实现，尚未接入光鸭即时事件监听。自动请求会合并，并等待已有同步任务结束。

CD2 完整路径前缀当前适配为 `/CloudNAS/CloudDrive`。其他挂载位置需要调整 `plugin/jobs/rules.js` 及相应前端副本，或选择链接模式。

当前只有静态语法、清单、依赖和打包检查记录；未声称完成 NAS 整理触发、账号登录、播放或清理的端到端验证。详细设置与边界见 [插件说明](plugin/README.md)。

## 构建

需要 Node.js 20 或更高版本，不依赖第三方 npm 包：

```sh
npm run pack
```

输出到 `dist/guangya-strm-0.6.3.dian115p`，构建工具拒绝覆盖已存在的同名文件。
