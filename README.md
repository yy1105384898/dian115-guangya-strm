# DIAN115 光鸭 STRM 同步与文件清理插件

面向 DIAN-115 插件平台的光鸭 STRM 同步插件。单账号登录，网盘目录浏览，CD2 路径或链接模式生成 STRM，元数据同步、光鸭文件清理、空目录清理、一次性任务和定时执行。

## 安装

在 DIAN115 插件中心导入 `.dian115p` 文件。当前版本 **1.0.3**，本地构建包位于 `dist/`，要求宿主插件 API **3.8**。GitHub [Releases](https://github.com/yy1105384898/dian115-guangya-strm/releases) 中的既有发布包保留在 `releases/`；1.0.3 尚未发布 Release。

已有插件使用升级入口，不需要卸载。账号、规则和同步状态由宿主插件存储保留。

## 功能

- 顶部页签：STRM 同步、文件清理、账号登录；共用一个光鸭账号，支持短信登录或手动导入凭证。
- 直接浏览光鸭源目录，自动读取 CD2 光鸭挂载名称。
- 生成本地 STRM，支持 CD2 完整路径与播放链接两种模式。
- 定时增量、定时全量；接收宿主整理事件并核对成功记录，合并触发对应规则增量同步。
- 可选同步 NFO、图片、字幕，支持后缀与排除目录设置。
- 孤立文件先预览再确认清理；任务进度统一在宿主系统任务队列查看。
- 文件清理支持删除选中文件、保留选中文件、清理不含保留文件的子目录；支持视频/字幕/音频/后缀和大小条件、空目录、排除目录、Telegram 通知及北京时间 Cron 定时。
- 单条规则支持预览或确认后清理；一次性清理使用独立空白表单，支持预览和立即清理，不保存为定时规则。定时需同时开启统一开关和规则定时选项；同步与云端清理互斥执行。
- 清理任务队列展示扫描数、预计和已清理数量、阶段及结果，支持单条删除及清空所有已结束记录。
- 整理明确因目标文件已存在而跳过时，按记录直连光鸭删除重复来源文件，保留目标。具体条件见下文。

## 光鸭文件清理

“文件清理”与“STRM 同步”“账号登录”同在一个插件内，共用光鸭登录账号。清理直接调用光鸭接口，目录从光鸭账号读取和选择，无需通过 CD2 删除。

### 三种清理方式

| 方式 | 行为 |
| --- | --- |
| 删除选中文件 | 删除满足文件类型、后缀或大小条件的文件，其余文件保留。 |
| 保留选中文件，删除其余文件 | 保留符合条件的文件，删除范围内其他文件。 |
| 仅清理不含保留文件的目录 | 逐级判断子目录，没有符合保留条件的文件时清理该子目录及内容；所选根目录直属文件保留。 |

可选全部文件、视频、字幕、音频和自定义后缀；大小条件支持与文件类型组合。开启“清理空目录”可清理原有空目录及本次清理后变空的目录。不选文件条件、只开启空目录清理时，所有文件保留。

### 已保存规则

1. 点击“新建规则”，填写名称，选择要清理的光鸭子目录。
2. 设置清理方式、文件条件、空目录选项，以及需要整目录保留的排除目录。
3. 保存后，点击“预览”生成候选清单；预览本身不删除文件，可核对清单后确认执行。
4. 也可点击规则旁的“清理”，在确认气泡中确认后，后台重新扫描并按规则执行。

### 一次性清理

点击顶部“一次性清理”，打开独立的空白任务窗口。任务名称可选，目录和清理条件自己填写。

- **预览结果**：仅扫描和统计候选数量，记录进入任务队列，当前表单保留。
- **开始清理**：确认范围后重新扫描并执行；可使用预览后的当前配置。
- 临时任务只执行一次，不新增已保存规则，也不加入统一定时。

### 定时与通知

在规则中开启“启用此规则”和“加入统一定时执行”，再开启页面中的统一定时并保存 Cron。时间按**北京时间**计算：

| Cron | 执行时间 |
| --- | --- |
| `0 3 * * *` | 每天凌晨 3 点 |
| `0 0 3 * * *` | 每天凌晨 3 点，六段格式且秒字段为 0 |
| `0 */6 * * *` | 每 6 小时 |

Telegram 可分别开启任务开始、任务结束通知，使用 DIAN115 已配置的通知渠道。

### 任务队列与目录保护

清理页队列显示任务名称、编号、定时/手动/仅预览、扫描文件数、预计和已清理的文件/文件夹数量、当前阶段及结果。点击任务名称可看详情，右侧垃圾桶移除插件内记录；移除记录不会删除网盘文件或宿主系统任务历史。系统任务队列可查看执行日志。

所选源目录本身和排除目录始终保留。清理删除的是**光鸭云端真实文件**；STRM 规则中的“清理孤立”则处理本插件跟踪的本地输出。宿主整理、转存目录不会自动加入排除列表，需要整目录保留时请手动排除。删除前核对目录和文件状态，无法确认结果时停止，不自动重发删除。

## 整理触发与重复来源删除

在同步规则中开启“启用”和“实时监控”。这里的实时监控是 **DIAN115 整理事件及整理记录检测**，不监控光鸭网盘变化，也不注册 CD2 目录监听。

| 整理结果 | 插件行为 |
| --- | --- |
| 整理成功，目标位于同步规则源目录内 | 登记目标父目录，合并后扫描该目录及子目录，增量生成 STRM。 |
| 跳过，原因明确为“目标文件已存在（跳过-已完成）” | 核对记录和光鸭源、目标，直连光鸭删除该条记录中的来源文件；目标保留。 |
| 其他跳过、一般错误或无法核对的记录 | 不据此删除文件。 |

整理事件按 3 秒窗口合并，每分钟补查整理成功记录；任务排队或运行时可能延后。手动同步和定时增量仍扫描所选源目录并跳过未变化输出，全量扫描重建输出；不是光鸭云端变化游标。

### 重复来源删除的范围

- 重复来源检测每分钟检查一次。只处理该功能**首次运行以后**产生的记录，不回溯旧历史；本次截图中安装前的记录不会补删。
- 整理记录状态必须为跳过，原因必须匹配上述明确文字。以宿主的去重结果为依据，不再通过 Emby 身份查询猜测重复，也不自行比较画质。
- 来源和目标须位于同一个已识别的光鸭挂载，目标在已启用且开启实时监控的同步规则内；来源必须位于**所有 STRM 同步源目录之外**。例如来源 `/光鸭云盘/待整理/视频.mkv`，目标 `/光鸭云盘/已整理/…/视频.mkv`。
- 目标不能命中该规则排除目录。源和目标必须是不同的非空文件，核对账号、文件 ID、大小、修改信息及整理记录后才提交来源 ID。
- 仅直连光鸭删除来源文件，不经 CD2 删除，不删除目录和目标文件；不影响其他网盘。
- 删除提交前持久化状态，响应或结果不明时不自动重发，等待人工核查。外部客户端在最后核对与请求之间修改网盘仍存在竞争窗口。
- 同步、云端清理和重复来源清理互相检查任务状态；未完成或需核对的任务可能使自动执行延后。

## 同步日志与 Emby 刷新

规则表下方只有一个 **同步日志** 区域：显示实际同步结果和“重复来源清理”，按时间排列，仅显示北京时间当天记录，固定高度滚动。

- 同步日志详情包含触发来源、扫描目录、STRM 新建/更新数量及实际耗时。
- 重复来源清理详情包含跳过原因、来源路径、保留目标及删除结果；失败时显示错误。
- 支持单条删除、清空已结束记录。删除只移除插件页面记录，不删除媒体、不清除宿主系统任务历史，也不改变重复删除的防重放状态。
- 不再逐个查询 Emby 中的电影或季集，不展示旧版“入库匹配／查询待重试”记录。

STRM 或相关元数据实际变更后，后台合并请求默认 Emby 全库扫描，至多每分钟一次；必须先配置默认实例，并将本地 STRM 输出目录加入 Emby 媒体库。扫描请求成功不代表文件已经入库，刷新失败保留待重试。插件不向宿主总览写入虚假入库记录，原生系统“运行日志”分类表也没有公开插件写入接口。

## 使用范围与验证

CD2 完整路径前缀当前适配为 `/CloudNAS/CloudDrive`，其他挂载位置需调整路径适配或选择链接模式。链接模式的目录扫描和删除使用登录的光鸭账号；整理记录匹配仍需要宿主的光鸭挂载路径。

1.0.3 已完成语法、插件结构和打包检查。用户此前反馈定时清理成功；**最新整理自动触发、重复来源自动删除及 Emby 刷新未完成 NAS 现场验证，本轮未执行真实云端删除**。检查通过不等于现场业务已成功。详见 [插件说明](plugin/README.md) 和 [版本记录](RELEASE_NOTES.md)。

## 构建

需要 Node.js 20 或更高版本，不依赖第三方 npm 包：

```sh
npm run pack
```

输出到 `dist/guangya-strm-1.0.3.dian115p`，构建工具拒绝覆盖已存在的同名文件。

结构检查：`node tools/project-check.mjs plugin`。此检查不代表 NAS 业务流程验证成功。
