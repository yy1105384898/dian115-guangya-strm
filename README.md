# DIAN115 光鸭 STRM 同步插件

面向 DIAN-115 插件平台的光鸭 STRM 同步插件。单账号登录，网盘目录浏览，CD2 路径或链接模式生成 STRM，元数据同步，定时同步和整理结果监控。

## 安装

在 DIAN115 插件中心导入 `.dian115p` 文件。当前开发版 **0.7.20**，本地构建包位于 `dist/`，要求宿主插件 API **3.8**。GitHub [Releases](https://github.com/yy1105384898/dian115-guangya-strm/releases) 中的既有发布包保留在 `releases/`；0.7.20 尚未发布 Release。

已有插件使用升级入口，不需要卸载。账号、规则和同步状态由宿主插件存储保留。

## 功能

- 顶部页签：STRM 同步、文件清理、账号登录；共用一个光鸭账号，支持短信登录或手动导入凭证。
- 直接浏览光鸭源目录，自动读取 CD2 光鸭挂载名称。
- 生成本地 STRM，支持 CD2 完整路径与播放链接两种模式。
- 定时增量、定时全量；接收宿主整理事件并核对成功记录，合并触发对应规则增量同步。
- 可选同步 NFO、图片、字幕，支持后缀与排除目录设置。
- 孤立文件先预览再确认清理；任务进度统一在宿主系统任务队列查看。
- 文件清理支持删除选中文件、保留选中文件、清理不含保留文件的子目录；支持视频/字幕/音频/后缀和大小条件、空目录、排除目录、Telegram 通知及北京时间 Cron 定时。
- 单条规则支持预览或确认后清理；一次性清理使用独立空白表单，支持预览和立即清理，不保存为定时规则。定时需同时开启统一开关和规则定时选项；同步与云端清理互斥执行。
- 清理任务队列展示扫描数、预计和已清理数量、阶段及结果，支持移除插件内记录。

## 使用范围与当前限制

**实时增量尚未完成，不能按原生 115 的云端实时监控使用。** 当前代码接收宿主整理事件、检查成功历史，并注册 CD2 目录轮询监听；触发后仍扫描完整源目录，增量仅跳过未变化的输出。CD2 轮询不是光鸭云端事件订阅。用户现场反馈自动触发未生效，尚未定位并验证修复。

**尚未接入宿主入库更新链路。** 生成 STRM 不代表 Emby 已扫描或宿主总览已更新。上述问题保留为当前已知限制。

CD2 完整路径前缀当前适配为 `/CloudNAS/CloudDrive`。其他挂载位置需要调整 `plugin/jobs/rules.js` 及相应前端副本，或选择链接模式。

v0.7.20 完成语法、插件结构检查和打包；用户已反馈定时清理成功。最新一次性清理流程及实时监控尚未在 NAS 完成验证。删除结果不明确时停止，不自动重发。需要整目录保留时，请在规则中手动排除。详见 [插件说明](plugin/README.md) 和 [版本记录](RELEASE_NOTES.md)。

## 构建

需要 Node.js 20 或更高版本，不依赖第三方 npm 包：

```sh
npm run pack
```

输出到 `dist/guangya-strm-0.7.20.dian115p`，构建工具拒绝覆盖已存在的同名文件。

结构检查：`node tools/project-check.mjs plugin`。此检查不代表 NAS 业务流程验证成功。
